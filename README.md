# Fit Check

A personal wardrobe app for two people. It suggests outfits from your actual
logged closets based on live local weather.

Open the app → it knows the weather where you are → you pick an occasion →
it gives you 3 outfit options built only from clothes you actually own.

## Stack

- Vite + React + TypeScript
- Tailwind CSS (v4, via `@tailwindcss/vite`)
- All data lives in `localStorage` — no backend, no auth
- No API keys required for weather (Open-Meteo). Outfit suggestions call the
  Anthropic API directly from the browser (see **Outfit suggestions** below).

## Getting started

```bash
npm install
npm run dev
```

Open the printed local URL on your phone (same network) or desktop. The app
is mobile-first and designed to live on a phone home screen.

```bash
npm run build    # type-checks and produces a static dist/ you can host anywhere
npm run preview  # serve the production build locally
```

## Testing on your phone

This app is meant to live on a phone home screen, so test it on one. Browser
geolocation only works in a **secure context** — over plain
`http://192.168.x.x` it fails no matter what, so the LAN dev server needs
HTTPS:

```bash
npm run dev:phone
```

That serves over HTTPS with a self-signed cert and prints a `Network:` URL
(`https://192.168.x.x:5173/`). Open that on your phone, on the same Wi-Fi.
Safari and Chrome will warn that the certificate isn't trusted — that's
expected for a self-signed cert. Tap through ("Show details" → "visit this
website" on iOS) and the page becomes a genuine secure context, so the
location prompt appears and geolocation works.

Your `.env` key is still picked up in this mode, so outfit suggestions and the
find checker work here too.

If the certificate warning gets tedious, two alternatives give you a properly
trusted cert:

- [`mkcert`](https://github.com/FiloSottile/mkcert) — issues a locally-trusted
  cert; install its CA on the phone once and the warning is gone for good.
- [`cloudflared`](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/)
  — `cloudflared tunnel --url http://localhost:5173` gives a public
  `https://….trycloudflare.com` URL with a real certificate. Note this exposes
  your dev server, and therefore your bundled API key, to anyone with the URL
  while it's running.

To add the app to your home screen: open it in Safari, Share → "Add to Home
Screen."

## Screens

- **Today** — weather for your location, an occasion picker, and 3 suggested
  outfits built from your logged closet.
- **Closet** — your full inventory, filterable by category, with edit/delete.
  Trousers below a profile's minimum rise are flagged and excluded from
  suggestions.
- **Add** — a plain form to log a new piece (no photo recognition — you type
  what it is).
- **Gaps** — a running list of things you're hunting for, plus a "check this
  find" evaluator for when you're standing in a store.

Two profiles (switchable from the header) each keep their own closet, gap
list, and style rules, stored under separate `localStorage` keys.

## Weather

Weather comes from [Open-Meteo](https://open-meteo.com/), which is free,
requires no API key, and allows CORS from the browser. Location resolution,
in order:

1. Browser geolocation (`navigator.geolocation`)
2. A manually entered location (geocoded via Open-Meteo's geocoding API),
   saved to `localStorage`
3. New York, NY, as a last-resort default

Manual location entry is always available as an escape hatch, and failures
(permission denied, timeout, network error, place not found) are surfaced
with their specific cause rather than a generic error.

## Outfit suggestions

Suggestions are generated by calling the Anthropic API (`claude-sonnet-5`)
with your full closet, the current weather, the selected occasion, and your
profile's hard style rules, asking for exactly 3 outfits back as JSON. Each
suggested item is validated against your actual closet — anything the model
invents that isn't in your closet is flagged rather than silently shown.

Set your key in `.env` (see `.env.example`):

```
VITE_ANTHROPIC_API_KEY=sk-ant-...
```

**Security note:** this reads the key via `import.meta.env`, which means it
is bundled into the client and visible to anyone with access to the app. That's an
acceptable tradeoff for a personal app running on your own device, but it is
**not** safe for anything you'd deploy publicly — a real deployment needs a
small server-side proxy that holds the key and forwards requests, so the key
never reaches the browser.

## Data reset

Settings includes a "reset to seed data" option per profile, which restores
the original seeded closet and gap list and discards any edits.
